# الأقصى — AlAqsa

**نظام إدارة عملاء وصيانة كاميرات المراقبة**
*CCTV Client & Maintenance Management System*

<div align="right">

تطبيق سطح مكتب لنظام ويندوز، مصمَّم لمحلات كاميرات المراقبة في الإمارات، لتوثيق العملاء وفروعهم ومعداتهم وزيارات الصيانة، وإصدار التقارير الاحترافية.

</div>

---

## 🔑 المزايا الرئيسية

| الميزة | الوصف |
|---|---|
| 🔐 **قاعدة بيانات مشفّرة** | تشفير AES-256 كامل (SQLCipher) — الملف غير قابل للقراءة بدون المفتاح |
| 🗝 **مفتاح استرداد** | مفتاح احتياطي يُعرض مرة واحدة، قابل للإبطال والتجديد |
| 👥 **عملاء وفروع** | شخص / شركة / محل / مطعم / فيلا — مع عدد غير محدود من الفروع |
| 📷 **معدات مرنة** | من كاميرا واحدة إلى 100+ لكل فرع، مع NVR/DVR/أقراص/سويتشات/UPS |
| 🏷 **باركود و QR** | قارئ سلكي أو كاميرا، وملصقات QR قابلة للطباعة لكل جهاز |
| 🛠 **زيارات الصيانة** | قائمة فحص من 9 بنود، فحص كل كاميرا، القطع المستبدلة، توقيع رقمي |
| 📄 **تقارير احترافية** | PDF عربي + Excel + مشاركة عبر واتساب أو طباعة |
| 🔔 **تنبيهات ذكية** | مواعيد الصيانة، انتهاء الضمانات، تجديد رخص الكاميرات |
| 📋 **رخص الكاميرات** | تتبّع تواريخ الإصدار والتجديد والانتهاء (نظام الإمارات) |
| 📁 **وثائق مشفّرة** | جوازات، هويات، رخص تجارية، تعهدات، مخططات، صور |
| 💰 **متابعة مالية** | فواتير وعقود صيانة سنوية، ووسم العملاء المتأخرين تلقائياً |
| 🎨 **ألوان الحالات** | تمييز السجلات بالألوان (مكتمل / جارٍ / متابعة / عطل) + ألوان مخصّصة |
| 🖧 **مشاركة محلية** | 2–3 أجهزة في المحل تعمل على نفس البيانات عبر الشبكة |
| 🌐 **لغتان** | العربية (افتراضي، RTL) والإنجليزية |
| 🌙 **وضع ليلي** | مظهر فاتح وداكن مريح للعين |

## 📥 التنصيب

راجع **[دليل التنصيب](docs/دليل-التنصيب.md)** للخطوات الكاملة.

باختصار:

1. شغّل `scripts/setup-certificate.ps1` كمسؤول (مرة واحدة على كل جهاز).
2. نصّب `AlAqsa-Setup-1.0.0.exe`.
3. عند أول تشغيل: أنشئ كلمة السر الرئيسية **واحفظ مفتاح الاسترداد فوراً**.

## 🗄 أين تُحفظ البيانات؟

```
%AppData%\Roaming\AlAqsa\
├── alaqsa.db        قاعدة البيانات (مشفّرة)
├── files\           الوثائق والصور (مشفّرة)
├── backups\         النسخ الاحتياطية
└── reports\         التقارير الصادرة
```

> **مهم:** البيانات خارج مجلد التطبيق تماماً. إلغاء التنصيب أو تثبيت تحديث **لا يمسّها إطلاقاً**.

## 🛠 التطوير

```bash
npm install          # تثبيت الحزم
npm run dev          # وضع التطوير (Vite + tsc watch)
npm run build        # بناء كامل
npm run package      # إنشاء ملف التنصيب
npm run typecheck    # فحص الأنواع
```

### البنية

```
src/
├── main/            نواة Electron
│   ├── db/          قاعدة البيانات والمستودعات
│   ├── security/    التشفير، مفتاح الاسترداد، الترخيص
│   ├── services/    التقارير، Excel، QR، الشبكة، التنبيهات
│   ├── storage/     المسارات ومخزن الملفات المشفّر
│   └── ipc/         تسجيل قنوات الاتصال
├── preload/         الجسر الآمن
├── renderer/        واجهة React
│   ├── components/  المكونات المشتركة
│   ├── screens/     الشاشات
│   ├── i18n/        الترجمة
│   └── styles/      نظام التصميم
└── shared/          الأنواع والثوابت المشتركة
```

### التقنيات

Electron 32 · React 18 · TypeScript 5 · SQLCipher (better-sqlite3-multiple-ciphers) · pdfmake · ExcelJS · Vite 5
